입찰참가 이력 검색

회사명 또는 사업자등록번호(+대표자명)로 기간 내 입찰참가 사업과
평가순위·평가점수를 검색합니다. 문의사항은 labq@labq.kr로 남겨주세요.

(주)·주식회사·공백 무시. 사업자등록번호와 둘 중 하나만 입력해도 됩니다.
하이픈(-)은 넣어도, 빼도 됩니다.
입력하면 회사명/사업자번호 조건에 추가(AND)로 적용됩니다.
개찰일 기준입니다. 기간이 길수록 조회 시간이 오래 걸려요.
입력하면 해당 키워드가 포함된 공고만 조회해 시간이 크게 단축됩니다.
API 일일한도 보호용 — 최대 5,000회, 기본 1,000회 (운영계정 기준).
