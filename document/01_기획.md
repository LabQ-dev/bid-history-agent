# 01. 기획서 — 입찰참가 이력 검색 에이전트 (bid-history-agent)

## 1. 배경 및 문제 정의

- 나라장터(국가종합전자조달)에서 **"특정 업체가 어떤 사업에 입찰 참가했고, 몇 위를 했는지"**
  (평가순위 + 기술/가격/종합 평가점수)를 기간 단위로 검색하고 싶다.
- 그러나 조달청 **나라장터 낙찰정보서비스 OpenAPI는 업체 기준 검색을 제공하지 않는다.**
  제공되는 조회 축은 **공고번호** 또는 **기간(개찰일시 범위)** 뿐이다.

## 2. 해결 아이디어

업체 기준 검색이 없으므로, **기간 기준 조회를 우회 활용**한다.

```
1) 기간 내 개찰완료 공고 목록을 전부 훑는다 (스윕)
2) 공고별 참가업체·순위·평가점수를 조회하고 캐시에 저장한다
3) 캐시된 참가업체 데이터에서 회사명/사업자번호로 로컬 필터링한다
```

이 방식의 비용(공고 1건당 API 1회)이 크므로, **일일 수집기**로 매일 전날 데이터를
미리 캐시에 쌓아 검색을 즉시화하는 것이 기획의 핵심이다.

## 3. 목표

| 구분 | 목표 |
|---|---|
| 핵심 가치 | 업체명/사업자번호만으로 기간 내 입찰참가 이력 + 순위·평가점수를 한 번에 조회 |
| 산출물 | 웹 검색 화면 + 엑셀(XLSX/CSV) 다운로드, CLI |
| 운영 형태 | 사무실 공용 컴퓨터(또는 서버)에 상시 구동, 팀원이 브라우저로 공동 사용 |
| 비용 | 공공데이터포털 무료 API만 사용 (개발계정 1,000회/일 한도 내 운용) |

## 4. 사용자 및 사용 시나리오

**대상 사용자**: 본인 + 팀원 (사무실 공용 컴퓨터에 띄워 브라우저로 공동 사용, 비개발자 포함)

- 시나리오 A — 업체 기준 검색: 회사명(또는 사업자번호+대표자명) + 기간으로 검색 →
  참가 공고 목록과 순위·평가점수를 표로 확인, 1위(낙찰) 건 하이라이트 → 엑셀 다운로드
- 시나리오 B — 공고 기준 확인: 공고번호로 해당 공고의 참가업체 전체 순위표 조회

## 5. 범위

### 포함 (In Scope)
- 낙찰정보서비스의 개찰결과 4종(물품/공사/용역/외자) 검색
- 참가업체별 개찰순위, 투찰금액, 기술/가격/종합 평가점수
- 일일 자동 수집(collector) 및 과거 소급 수집(백필)
- 팀 공유 배포 (Docker, systemd, 비밀번호 보호)

### 제외 (Out of Scope)
- 진행 중(개찰 전) 공고 검색 — 개찰완료 건만 대상
- 나라장터 외 조달 플랫폼 (국방전자조달 등)
- 알림/구독 기능 → 별도 프로젝트 `bid-alert-agent`에서 담당
- 회원/권한 관리 — 팀 공용 비밀번호(Basic Auth) 수준으로 충분

## 6. 제약 조건

- **API 일일 한도**: 개발계정 1,000회/일. 공고 1건당 상세조회 1회가 필요하므로
  긴 기간 검색은 하루에 못 끝날 수 있음 → 캐시 + 이어서 조회 + 일일 수집으로 완화
- **CORS/키 노출**: 공공데이터포털 API는 브라우저 직접 호출이 차단되고, 인증키를
  HTML에 넣으면 노출됨 → 정적 HTML 불가, 로컬 서버가 API 호출을 대행해야 함
- **조회기간 제한**: 개찰결과 목록 API는 1회 조회기간이 1개월 이내 → 30일 단위 분할 조회

## 7. 성공 기준

- 수집된 기간에 대한 검색은 API를 거의 쓰지 않고 즉시 완료
- 팀원이 브라우저만으로 검색·엑셀 다운로드를 수행 가능
- 일일 수집이 무인으로 동작하고, 한도 초과 시에도 다음 실행 때 이어서 수집
